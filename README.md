# Project One — Management Company Website

![Vercel Deploy](https://img.shields.io/badge/Deployed%20on-Vercel-000?logo=vercel&style=flat-square)

A sleek and professional website built for **Project One**, a modern management company. This site was developed using **Next.js** and deployed on **Vercel** to ensure fast performance, scalability, and a seamless user experience.

## 🔗 Live Demo

🌐 [Visit the Live Site](https://project-one-j8f2-adqr6d70e-kingreaper6940s-projects.vercel.app/)  
Deployed via [Vercel](https://vercel.com)

## ✨ Features

- ⚡ **Next.js** for high performance and server-side rendering  
- 📱 Fully **responsive** and mobile-friendly design  
- 🔍 **SEO-optimized** metadata and page structure  
- 📄 Clean sections for **Services**, **About**, and **Contact**  
- ✅ Contact form with validation  
- ☁️ **Live on Vercel** with fast global delivery

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/)  
- **Language:** JavaScript  
- **Styling:** CSS Modules  
- **Deployment:** [Vercel](https://vercel.com/)

## 🚀 Getting Started

1. **Clone the repo:**
   ```bash
   git clone https://github.com/yourusername/project-one.git
   cd project-one
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Deployment

This project is deployed via [Vercel](https://vercel.com).  
To deploy your own fork:

```bash
npm i -g vercel
vercel --prod
```
